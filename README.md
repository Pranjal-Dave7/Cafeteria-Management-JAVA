# Cafeteria-Management-JAVA
A Java CLI cafeteria ordering system built with OOPS principles and MySQL connectivity.

Problem statement: During peak lunch hours at uni's cafeteria, students often spend 15-20 min waiting in line and then another 20 minutes for their order to get ready. 

Solution: Cafeteria Management system solves this by enbaling pre-ordering directly from classrooms before break begins, turning chaotic queue into seamless pick-up and dine-in experience. 
 

## Key Features
- ## Multi Vendor Management:** Interactive menus and dynamic billing system.
- ## Automated Table Allocation System:** Tracks table capacity (4-person vs 6-person), handles dining availability, and implements a timed auto-release for occupied tables.
- ## Exception handling:** Validates numerical item selections, handles invalid inputs, and manages database connection state.
- ## Database Architecture:** Queries live vendor item lists and prices directly from MySQL.
